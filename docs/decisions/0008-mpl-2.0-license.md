# 0008. License: MPL-2.0

- **Status:** Accepted. Amended by [0023](0023-copyright-notices.md) (rule 2) and [0034](0034-noto-fonts-under-ofl.md) (rule 4).
- **Date:** 2026-11-24

## Context

ASPIS is an open-source operating system. The options were a permissive license (Apache-2.0 or MIT), file-level copyleft (MPL-2.0), or strong copyleft (GPL-2.0).

<!-- REUSE-IgnoreStart -->

## Decision

1. All ASPIS code (kernel, servers, libraries and tools) is licensed under the Mozilla Public License 2.0.
2. Each source file begins with `SPDX-License-Identifier: MPL-2.0`.
3. The canonical MPL-2.0 text goes in `LICENSE` when the repository is created.
4. Dependencies must be compatible: permissive licenses (MIT, Apache-2.0, BSD) or MPL-2.0. The kernel and core servers don't use GPL-only dependencies.
5. The documentation license will be decided separately.

<!-- REUSE-IgnoreEnd -->

## Consequences

- Modified ASPIS files stay open when they're distributed. Applications and new files built on ASPIS can use any license.
- MPL-2.0 includes an explicit patent license.
- MPL-2.0 is less common than MIT or Apache-2.0 in the Rust ecosystem, though Oxide's Hubris microkernel uses it.
